🏨 Hospitality Analysis

A data analytics project focused on analyzing hotel booking data to understand revenue, occupancy, bookings, cancellations, and hotel performance.

📊 Key Analysis

Hotel & room category performance

Revenue and booking trends

Occupancy and capacity utilization

Booking & cancellation analysis

Booking platform performance

Customer ratings

🛠️ Tools Used

SQL

Excel

Python

📁 Dataset

The project includes hotel, room, date, booking, and aggregated booking datasets.

💡 Objective

To transform raw hospitality data into meaningful business insights and KPIs that can support better revenue and operational decisions.
